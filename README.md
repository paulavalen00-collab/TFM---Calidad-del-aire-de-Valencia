# Valencia Verde 2030
## Análisis y predicción de indicadores ambientales urbanos con tecnologías Big Data

Trabajo Fin de Máster del Máster Universitario en Análisis y Visualización de Datos Masivos de la Universidad Internacional de La Rioja (UNIR).

## Objetivo del proyecto

Analizar la evolución de la calidad del aire en Valencia mediante tecnologías Big Data y modelos predictivos, con el fin de evaluar su evolución respecto a los objetivos europeos de calidad del aire establecidos para 2030.

Se estudian cuatro contaminantes: NO₂, PM₁₀, PM₂,₅ y O₃, junto con información complementaria de tráfico, meteorología y contaminación acústica.

## Tecnologías utilizadas
- Python y PySpark
- Google Cloud Storage
- Google Cloud Dataproc
- SQL
- Power BI

## Organización del repositorio

El código está organizado según los apartados del capítulo 6 de la memoria del TFM:

- 01_comprension_datos:
Esta carpeta contiene los notebooks utilizados para la exploración y caracterización inicial de los conjuntos de datos del proyecto.
Corresponde al apartado 6.2 de la memoria del TFM.

- 02_preparacion_datos: limpieza y transformación.
- 03_integracion_gold: construcción del modelo dimensional.
- 04_analisis_calidad_aire: análisis estadísticos, temporales y espaciales.
- 05_modelos_predictivos: desarrollo de los modelos.
- 06_evaluacion_modelos: evaluación y comparación.
- 07_visualizacion_powerbi: archivos relacionados con el dashboard.
